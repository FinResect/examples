# fast-neural-style 使用说明（支持 1/4 通道）

本目录是 `fast_neural_style`（Fast Neural Style，基于感知损失 + InstanceNorm）的本地版本。
已对 `TransformerNet` 增加 `--width` 通道缩放参数，可训练更轻量的模型（如 1/4 通道）。

## 一、环境准备

```bash
pip install -r requirements.txt
```

需要 `pytorch`、`torchvision`、`scipy`。GPU 非必需，但能显著加速训练。

## 二、通道缩放（--width 参数）

`TransformerNet` 原版通道为 `32 → 64 → 128`。`--width` 会按比例缩放全部通道：

| --width | 实际通道 | 说明 |
|---------|----------|------|
| 1.0     | 32/64/128 | 默认，原版模型 |
| 0.5     | 16/32/64  | 半通道 |
| 0.25    | 8/16/32   | **1/4 通道**，最轻量 |

> 注意：推理时的 `--width` 必须与训练时完全一致，否则 `load_state_dict` 会报 size mismatch。

## 三、训练自己的模型

```bash
cd /home/fin-resect/Program/FPGA/examples/fast_neural_style

python neural_style/neural_style.py train \
  --dataset /path/to/train-dataset \
  --style-image images/style-images/mosaic.jpg \
  --save-model-dir /path/to/save-model/folder \
  --epochs 2 \
  --width 0.25 \
  --accel
```

常用参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--dataset` | （必填） | 训练集路径，须指向「内部还含一层子文件夹」的目录（`ImageFolder` 按类别分文件夹） |
| `--style-image` | `images/style-images/mosaic.jpg` | 风格图路径 |
| `--save-model-dir` | （必填） | 训练好的模型保存目录 |
| `--width` | `1.0` | 通道缩放系数，`0.25` 即 1/4 通道 |
| `--epochs` | `2` | 训练轮数 |
| `--batch-size` | `4` | 批大小 |
| `--image-size` | `256` | 训练图尺寸 |
| `--content-weight` | `1e5` | 内容损失权重 |
| `--style-weight` | `1e10` | 风格损失权重 |
| `--lr` | `1e-3` | 学习率 |
| `--accel` | 关 | 启用加速设备（CUDA/MPS/XPU） |
| `--checkpoint-model-dir` | 无 | 设置后按 `--checkpoint-interval` 保存中间检查点 |

**训练集说明**：官方使用 COCO 2014 Training（80K 张 / 13GB），下载地址 https://cocodataset.org/#download 。
解压后需保证 `--dataset` 指向的目录下还有一个子文件夹包含全部图片，例如：

```
/path/to/train-dataset/
└── train2014/        # 图片都在这一层里
    ├── 0001.jpg
    └── ...
```

**调参建议**：
- 输出太糊 / 丢失内容 → 增大 `--content-weight`
- 风格不够强 → 增大 `--style-weight`
- 通道缩小后（如 `--width 0.25`）模型更小更快，但细节/风格表现会下降，可能需要重新调权重

训练完成后，模型会保存为：
`<save-model-dir>/epoch_<epochs>_<时间戳>_<content-weight>_<style-weight>.model`

## 四、用训练好的模型风格化图片

```bash
python neural_style/neural_style.py eval \
  --content-image /path/to/content.jpg \
  --model /path/to/save-model/folder/epoch_2_xxx_1e5_1e10.model \
  --output-image /path/to/output.jpg \
  --width 0.25 \
  --accel
```

| 参数 | 说明 |
|------|------|
| `--content-image` | 待风格化的内容图 |
| `--model` | 训练好的 `.model` 文件 |
| `--output-image` | 输出图路径 |
| `--width` | **必须与训练时一致** |
| `--content-scale` | 内存不足时缩放内容图（如 `2` 表示长宽减半） |
| `--export_onnx` | 额外导出 ONNX 模型到指定文件 |

## 五、快速自测（CPU，小规模）

不训练、仅验证推理链路可用：

```bash
python neural_style/neural_style.py eval \
  --content-image images/content-images/amber.jpg \
  --model <某训练好的.model> \
  --output-image /tmp/out.jpg \
  --width 0.25
```

```bash

```

> 预训练模型为原版 `--width 1.0`，推理时需用 `--width 1.0`（或不传）。
